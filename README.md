# Telegram Scraper (Node.js + TypeScript)

A powerful Telegram channel scraper built using **Puppeteer + TypeScript**, with automatic translation support.

---

## 🚀 Features

- Extract channel title, description, stats, subscribers
- Extract chart data
- Extract posts and reactions
- Automatic translation using local dictionary
- Modular architecture (utils, services)
- TypeScript strict mode
- Ready for GitHub / npm publishing

---

## 📦 Installation

```bash
git clone https://github.com/yourname/telegram-scraper
cd telegram-scraper
npm install
```
